# Dy\_Downloader(抖音作品批量采集下载器)开发方案

> 状态:方案定稿,未开工。范围:与 XHS\_Downloader 同形态的桌面工具 + 抖音「收藏列表」支持。

## 1. 目标与定位

在 `Dy_Downloader/` 中开发**功能对齐 XHS\_Downloader** 的抖音桌面工具:

- 桌面 GUI:**左侧内嵌浏览器**(可直接浏览抖音),右侧操作与数据

- 抓取主页作品列表(视频/图集),勾选后**加入后台下载队列**,下载不占用浏览器

- **收藏列表下载**(本人账号):默认收藏 + 自定义收藏夹

- 单篇作品下载、抓取记录、断点续传、单实例、登录态持久化

**参考双源**:

| 来源                                                                   | 借鉴什么                        |
| -------------------------------------------------------------------- | --------------------------- |
| 同仓 [XHS\_Downloader](../XHS_Downloader)(成熟)                          | 桌面形态、收割式采集、队列/续传/单实例等整套工程底座 |
| GitHub [jiji262/douyin-downloader](../douyin-downloader)(已 clone 研究) | 抖音数据链路、收藏端点形态、无水印/命名/去重思路   |

## 2. 关键调研结论(决定技术路线)

1. **抖音 web 签名逐请求变化,且收藏等端点受 Argus 风控门禁**(需要页面 SDK 补 `x-secsdk-web-signature` 等)。参考项目桌面版最终也是靠「隐藏登录窗口 + 页面桥」让浏览器页面补签名,并非纯代码实现签名。
2. 因此 Dy 版主路径 = **收割内嵌浏览器自己的请求**(与 XHS 同源、无需签名逆向),比参考项目更简:无需页面桥注入,登录态就在窗口里。
3. 抖音主页列表响应**自带播放地址**,列表即详情,可省去 XHS 的「逐篇详情 HTML」环节。
4. **收藏列表是三层结构**:账号级默认收藏(`POST /aweme/v1/web/aweme/listcollection/`)、自定义收藏夹列表(`GET /aweme/v1/web/collects/list/`)、单收藏夹作品(`GET /aweme/v1/web/collects/video/list/?collects_id=…`)。收藏夹 ID 必须用**字符串** `collects_id_str`(int64 经 JS 会丢精度)。
5. 图集/封面下载可能防盗链 → 下载通道需支持自定义 Header(Referer/Cookie)。

## 3. 功能需求

### 3.1 与 XHS\_Downloader 对齐的基线

| 功能     | 说明                                                         |
| ------ | ---------------------------------------------------------- |
| 内嵌浏览器  | 左侧实时页面 + 右侧操作;扫码/滑块在窗口内处理;UA 覆盖规避自动化指纹;会话过期自动弹登录码 + 登录状态指示 |
| 三种抓取   | 粘贴作者主页 URL / 单作品链接(自动解析短链 `v.douyin.com`)/ 留空抓取当前页面        |
| 作品列表   | 类型徽标(视频/图集)、封面缩略图、标题、点赞、勾选、全选/全选视频/全选图集、行点击勾选、悬停封面大图预览     |
| 单作品下载  | 浏览到单作品页面点「下载本作品」                                           |

| 后台下载队列 | 线程池消费;右下任务面板 等待/进行中/完成/失败;暂停/继续/重下失败                       |

| 下载产物   | 视频(去水印源)、图集原图;落盘 `作者/日期_标题_aweme_id/`;二次运行自动跳过             |

### 3.2 抖音特色:收藏列表(本人账号)

| 交互入口       | 说明                                                                                                              |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| 工具栏「抓收藏」按钮 | 自动导航 `https://www.douyin.com/user/self?showTab=favorite_collection` → 收割默认收藏 + 枚举自定义收藏夹(自动点开 + 自适应滚屏)→ 结果按收藏夹归组 |
| 收藏夹分组列表    | 右侧按收藏夹分组展示,勾选加入下载队列;跨收藏夹与跨作者按 `aweme_id` 去重                                                                     |
| 「抓当前」兜底    | 用户手动进入某收藏夹后,复用「留空抓当前页」逻辑收割该夹,滚动翻页由工具驱动                                                                          |
| 收藏落盘       | 目录 `目标目录/收藏/收藏夹名/…`;收藏夹名按文件系统规则清洗                                                                               |

> 收割监听对象(均发生在收藏页):`collects/list/`(收藏夹元数据)、`collects/video/list/`(夹内作品,按 `collects_id` 归组)、`aweme/listcollection/`(默认收藏流,POST)。

### 3.3 工程要求(本方案强制项)

1. **Cookie 本地持久化**

   - QtWebEngine 用户数据目录持久化(开发版 = 项目根,打包版 = `%LOCALAPPDATA%\DyCollector\`),实现重启免登录。

   - 页面登录后提取关键 Cookie 快照落盘 `cookies.json`(供后台 HTTP 下载/防盗链 Referer 通道使用)。

   - **所有测试(spike / 回归)统一读这份持久化 Cookie**,启动时先校验登录态(`/user/profile/self/` 探活),有效则直接跑、无效才提示一次扫码,避免测试过程中反复扫码。
2. **exe 进程唯一**

   - 复用 XHS 的 `single.py`:启动先 `QLockFile` 抢占,失败则 `QLocalServer` 唤醒已有窗口并退出新实例(打包版与源码版互斥)。重复双击 exe 只会置顶已有窗口。
3. **图标统一使用** **`logo.jpeg`**

   - `logo.jpeg` 为本项目唯一图标源图;开发阶段用 Pillow 转出多尺寸 `logo.ico`。

   - 三处生效:打包 exe 图标(`PyInstaller --icon=logo.ico`)、窗口/任务栏图标(`QIcon` 加载 `logo.ico`)、`.spec` 的 `icon` 与 `datas`(随包携带)。

   - 打包目录中同时保留 `logo.jpeg`(README 等文档用)。

## 10. 技术栈修订(Electron + Python 双栈,已确认)

> 2026-09 定稿:QtWebEngine 官方 Python 版不含 H.264/AAC 专有解码,内置浏览器无法播放抖音视频 → **换栈为 Electron 浏览器壳 + Python sidecar**。下述功能需求与章节仍有效,本节覆盖载体与架构。

### 10.1 架构

| 层             | 载体                                         | 职责                                                          |
| ------------- | ------------------------------------------ | ----------------------------------------------------------- |
| 浏览器壳          | Electron(`electron/`;Chromium 官方构建含 H.264) | 窗口、抖音页浏览/播放、扫码登录、`session` 持久化、进程单实例、暴露 CDP 9357            |
| 收割/下载 sidecar | Python(`dy_app/` + `.venv`)                | DrissionPage 挂 Electron CDP 收割(已验证)、Cookie 快照、下载/去水印/队列(后续) |
| UI 面板         | Vue3(规划)                                   | 列表勾选、任务队列、收藏夹分组(M1+)                                        |

## 11. M1 重新定义(M1-rev2,用户推翻批量方案)

> 用户新需求:不要“批量抓主页/抓收藏”列表式;改为 **对作品卡片 / 作品详情页右键直接下载该作品**(视频/图集);右侧面板 UI 对齐 [XHS\_Downloader](../XHS_Downloader) 风格。

### 11.1 产品形态(rev2)

| 界面   | 说明                                                                                                |
| ---- | ------------------------------------------------------------------------------------------------- |
| 左侧   | 抖音浏览器(首页/推荐/作者主页/收藏流/详情页),**全程零批量列表**                                                             |
| 交互   | ① 任意作品卡片(封面/标题)右键 → 「下载该作品」;② 作品详情页(视频/图集)内右键 → 「下载本作品」;③ 右键另含「复制作品链接」                            |
| 右侧面板 | 对齐 XHS 右栏:顶工具条(后退/前进/首页/打开目录/保存Cookie + ●登录灯) → 下载目录行 → 任务统计 → **下载队列表格**(状态/进度,重下失败·暂停·继续) → 日志区 |

### 11.2 技术拆解与关键链路

1. **右键命中检测**(preload 主世界):监听 `contextmenu`,检测指针处最近的作品链接(`/video|note|gallery|slides/{id}`)或详情页自身(`location.pathname` 命中)→ 浮层菜单(仿 XHS 右键交互)。
2. **单作品取流**(sidecar `collect_one`):

   - 优先:新 CDP 标签注入持久 Cookie(需把快照存**完整字段** domain/path/httpOnly/secure,主进程已可读 session.cookies)→ 打开作品详情 → 收割 `aweme/detail` 响应 → 归一 `{aweme_id,type,title,author,media[]}` → 关闭标签;

   - 兜底:当前 douyin 标签内临时导航详情收割后**返回原地址**(体验略差但可靠)。

   - 前提 **P0 spike\_c** 验证(注入 Cookie 是否可用 / detail 字段结构与去水印地址)。
3. **下载引擎**(平移 XHS download 思路):curl\_cffi + 页面 UA + Referer + Cookie 拉取视频/图集原图;落盘 `作者/日期_标题_aweme_id/`(视频 `视频.mp4`、图片 `01.jpg…`);文件级跳过、半截清理。
4. **队列**(主进程为中枢):右键 → 入队(`tasks.json` 持久化,断点续传)→ 逐个 spawn `download_one`(串行,稳且便于状态管理;后续再提并发)→ 进度经 IPC 刷到面板表格;支持 暂停/继续/重下失败。
5. **面板 UI**:Vue3 改造为 XHS 风格任务面板;移除批量列表/抓取按钮。

### 11.3 rev2 里程碑

- **P0** spike\_c:单作品详情取流闭环验证(新标签+Cookie 注入 or 当前标签导航兜底),解析出去水印视频与图集原图;下载 1 条验证

- **P1** 面板重构(XHS 风格队列面板)+ 移除批量功能

- **P2** 右键菜单(DOM 命中 + 浮层)+ IPC 入队/出队

- **P3** 下载引擎 + 队列持久化与任务状态(暂停/继续/重下失败)+ 命名落盘

- **P4** 回归与打包(单实例/图标已有)
