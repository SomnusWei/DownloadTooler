## 1. 【未解决】图集 / 图文作品下载失败（抖音临时风控窗口）

**状态**：待复测（需长冷却后低频验证）；已 mark，进入后续里程碑处理。

### 2026-09-03 重构为“页面驱动图集引擎”（独立模块 img\_engine）

- 图集取图不再依赖纯 HTTP：detail 失败/空/403 → `dy_app/img_engine.py` `page_pick()` 同登录 CDP 新开标签读 SSR 脚本解码抽图 URL（含 `\u002f\u0026`/`&amp;` 反转义、按核心路径去重）。

- 登录墙识别（扫码登录/验证码中间页）→ 抛“登录墙”错误；Electron 队列**自动暂停**并提示人工登录（`pauseOnWallIfNeeded`）。

- 会话加固：主进程每 3 分钟把浏览器最新 Cookie 同步 `cookies.json`；仅重试 1 次避免连发 403。

- 实测（已登录会话）：`/video/7547989401487740220` 取到 **30 张**图 URL ✅；随后**直接下载签名图 URL 仍 403**（疑 douyinpic CDN 反非浏览器请求）→ 下一步候选：走“浏览器响实体捕获”（hidden view 拦截 image 响应字节）通道，待冷却后低频验证。

- ⚠️ 反复自动请求会把会话打成验证码墙；**每轮间隔需 ≥10min，且只用 UI 单条触发**。

### 2026-09-03 浏览器响应体捕获通道（已打通）

- douyinpic 直连 403 为 **CDN 反非浏览器**（Cookies/Referer/Origin/sec-fetch 全试无效；页面内 fetch 也被 CORS 拦）。

- 解法：Electron 隐藏视图 `browserImageBytes()`：真实加载每张图（走浏览器网络栈，CDN 放行）→ debugger Network 截 `loadingFinished` → `getResponseBody` 取字节落盘。

- 实测：一次干净运行成功落盘 **15 张**（期间部分未加载全；已加 `backgroundThrottling:false` + 并发分片 + 立即取 body 修复）。

- 引擎侧：图片直连只试 1 次，403 即输出 `==DYC_IMGURLS==` 交主进程捕获（exit 9）；主进程识别后 `browserCaptureTask` 完成落盘并标记任务完成。

- ⚠️ 教训：**不要连跑脚本反复直连**——30×3 次 403 会把 douyinpic CDN 对 IP 临时拉黑（拉黑期浏览器加载也 0 张）。恢复后须冷却 10\~15min，且只用 UI 单条触发复核。

### 现象

- 视频作品：签名直连 `aweme/detail` → 无水印 mp4 下载 **正常**。

- 图集/图文（note 及 `/video/` 形态但 `aweme_type=68` 的图文）：

  - `detail.images[i].url_list / download_url_list / display_image` 全为空；

  - 引擎指数退避重试（8s→18s→36s）仍空；

  - 随后接口开始直接 **HTTP 403 Forbidden**；

  - SSR 兜底（主进程隐藏同登录视图取 `douyinpic.com/...aweme_images`）html 中也取不到图。

### 证据 / 判断

- 开发期**曾一次成功**取到 `p3-...douyinpic.com/~tplv-dy-aweme-images:q75.webp` 图 URL（且 206 可达）；

- 同一接口在**高频连发**后被服务端降级/封锁：空 URL → 403，多分钟冷却后仍 403；

- 对照已 clone 参考项目 `jiji262/douyin-downloader`：其取图**使用同一 detail 接口**（note 走 aid=6383；解析优先 `watermark_free_download_url_list / origin_image / display_image / url_list / download_url_list`，兼容 `image_post_info.images`），低频单条场景稳定。

- 结论：当前阻塞主要来自对**该登录态/IP 的图片 detail 临时风控**，非本地代码失效（初验已通）。
